# Thai Tax Calculator

A web application to calculate Thai personal income tax, helping users understand their tax obligations and potential savings through deductions.

## Features

- **Tax Calculation**: Calculate tax payable based on annual income.
- **Deduction Planning**: Determine deductions needed to reach a lower tax bracket.
- **Savings Analysis**: Visualize tax savings from deductions.

## Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/pakhapoom/pkz-lab.git
   ```
2. Navigate to the project directory:
   ```bash
   cd pkz/thai_tax_calculator
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal).

## Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs ESLint to check for code quality issues.
- `npm run preview`: Locally previews the production build.

## Technologies Used

- **React**: UI library.
- **Vite**: Build tool and development server.
- **ESLint**: Linting utility.
